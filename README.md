# BIT - Homework Project

A clean, responsive, and modern landing page built for the Business Information Technology (BIT) department at UOITC. This project showcases an educational institutional page with informational sections, resource links, and a contact form.

## 🚀 Features

* **Responsive Design:** Fully optimized for desktop and mobile devices using CSS Media Queries.
* **Modern UI:** Clean layout featuring smooth scrolling, geometric background shapes, and FontAwesome typography icons.
* **Informational Sections:** Dedicated zones for the department's vision, mission, and strategic goals.
* **Open Data Integration:** Fast-access portal links to real university data categories (Staff, Employees, Students, Researches, and Archived Projects).
* **Contact Form:** Form UI for user inquiries and static location details.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom properties/variables, Grid, and Flexbox layout models)

## 📦 How to Run

1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser (Chrome, Edge, Firefox, Safari).
